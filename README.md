# Student Loan System

## About the Project

Student Loan System is a web-based application designed to allow students to submit and manage loan applications through an easy-to-use web interface.

The system uses a Flask backend and MongoDB database to process and store student loan application information.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* MongoDB

## Main Features

* Student loan application form
* Loan approval processing
* Storage of applications in MongoDB
* Applications management
* Dashboard for viewing loan applications
* Search and filtering of applications
* Responsive web interface

## How to Run the Project

1. Install Python.
2. Install the required Python packages.
3. Make sure MongoDB is running.
4. Open the project folder in VS Code.
5. Run the Flask application.
6. Open the application in a web browser.
